## 📝 Descrição Curta

## 🛠️ Especificações Gerais da Linha

- **Material do Mancal:** Ferro Fundido Cinzento
- **Tipo de Rolamento:** Esferas com anel interno estendido e fixação por trava Allen
- **Recurso Autoalinhável:** Permite compensação angular do eixo
- **Manutenção:** Entrada para engraxadeira (bico graxeiro)
- **Aplicação:** Transmissão de potência, sistemas de transporte e máquinas industriais/agrícolas
