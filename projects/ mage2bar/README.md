# Mage2Bar

O **Mage2Bar** é um projeto de loja virtual desenvolvido em Magento 2, utilizando Docker.

O projeto simula uma loja voltada para bebidas e petiscos, sendo utilizado como ambiente de desenvolvimento e demonstração de uma aplicação Magento 2.

## Objetivo

O projeto tem como objetivo disponibilizar um ambiente Magento 2 estruturado em containers Docker, permitindo trabalhar com a preparação do ambiente, configuração da aplicação, infraestrutura e automação.

A estrutura também serve como base para estudos e desenvolvimento de soluções relacionadas a Magento 2 e DevOps.

## Tecnologias utilizadas

- Magento 2 Community Edition
- Docker
- Docker Compose
- Debian Linux
- Nginx
- PHP-FPM 8.2
- MariaDB
- Redis
- OpenSearch
- Terraform
- Git
- GitHub Actions
