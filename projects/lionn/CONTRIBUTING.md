# Contribuindo com o Projeto Lionn

Este documento descreve as diretrizes para contribuição com o projeto Lionn.

---

## Antes de Contribuir

- A contribuição está alinhada com o escopo do projeto.
- Não existe issue ou pull request semelhante já aberto.
- A documentação existente não cobre o ponto que você deseja tratar.

---

## Como Contribuir

### Reportando Problemas

Inclua:

- Descrição clara do comportamento observado.
- Descrição do comportamento esperado.
- Passos para reproduzir.
- Versões do Docker, Docker Compose e sistema operacional.
- Trechos relevantes de logs.

### Sugerindo Melhorias

Descreva:

- O problema que a melhoria resolve.
- A abordagem proposta.
- Alternativas consideradas.
- Impacto esperado.

### Enviando Pull Requests

- Focados em uma única alteração.
- Seguindo o padrão do `.editorconfig`.
- Incluindo atualização da documentação.
- Descrevendo claramente o que foi alterado.

---

## Padrões Adotados

### Código

- Shell: seguir o estilo dos scripts existentes.
- Dockerfile: manter organização em camadas e usuário não-root.
- Nginx: manter comentários bilíngues e estrutura de segurança.

### Documentação

- Idioma: português (pt_BR).
- Tom: técnico, direto.
- Estrutura: seguir a numeração sequencial.

### Commits

- `docs:` para documentação.
- `fix:` para correções.
- `feat:` para novas funcionalidades.
- `chore:` para manutenção.

---

## Código de Conduta

A participação pressupõe respeito mútuo.
